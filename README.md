# Нейроюрист по сделкам с жилой недвижимостью

Дипломный проект: ИИ-консультант для физических лиц по сделкам с **жилой** недвижимостью —
купля-продажа, наём, ипотека, ДДУ, дарение, рента, наследование, налоги при сделках с жильём,
государственная регистрация прав.

Архитектура: **RAG на FAISS** + многошаговая цепочка LLM
(разбор вопроса → поиск и генерация ответа со ссылками на нормы → проверка ответа) + история диалога.

## Структура репозитория

```
knowledge-base/         база знаний (~5.4 МБ, 87 txt-файлов)
  laws/                 ГК, ЖК, СК, НК, ФЗ-218/102/214 (релевантные главы/статьи)
  plenum/               10 постановлений Пленума ВС РФ
  practice/             48 файлов постатейной судебной практики ВС РФ
  obzory/               точечные пункты обзоров практики Президиума ВС РФ
  MANIFEST.md           опись: источник, статус редакции, обоснование периметра по каждому файлу
  extract_*.py, clean_*.py   скрипты извлечения текста из PDF/DOCX (pypdf / python-docx)
testset/
  test_questions.md     30 тестовых вопросов бытовым языком + эталонный ответ и источник
notebooks/
  neurojurist_prototype.ipynb   прототип (Этап № 3), запускается в Google Colab
requirements.txt
```

## Запуск прототипа

Открыть `notebooks/neurojurist_prototype.ipynb` в Google Colab, задать секрет `OPENAI_API_KEY`
(значок 🔑) и выполнить все ячейки по порядку. В первой ячейке клонирования указать URL этого
репозитория.

Модели: `text-embedding-3-small` (эмбеддинги), `gpt-4o-mini` (генерация), `temperature=0`.

## Источники базы знаний

ГАРАНT (garant.ru), КонсультантПлюс (consultant.ru), портал Верховного Суда РФ (vsrf.ru),
справочник постатейной практики ГК РФ (gkrfkod.ru). Тексты получены вручную из первоисточников
и извлечены локально без парсинга сайтов и без прогона через языковую модель — для юридического
RAG точность цитирования нормы критична. Подробности — в `knowledge-base/MANIFEST.md`.
